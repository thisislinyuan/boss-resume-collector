# BOSS 直聘简历自动筛选收藏工具

一个基于屏幕 OCR 的桌面自动化小工具，用于在 BOSS 直聘客户端里自动筛选并收藏符合条件（公司关键词 + 职位关键词）的候选人简历，同时提供图形界面来开关脚本、配置关键词、设置全局快捷键。

> 说明：本工具通过模拟鼠标点击与屏幕识别工作，**不会登录、抓取或导出任何数据**，仅在本地运行。

---

## 功能特性

- **关键词匹配收藏**：公司关键词与职位关键词"1+1"命中（同一行、公司关键词右侧）才收藏，避免误判。
- **只点击未读简历**：通过文字颜色区分黑色（未点击）与灰色（已点击），灰色自动跳过。
- **去重保护**：签名 + 坐标双重去重 + 已收藏状态检测，不会重复点开或重复收藏同一份简历。
- **已收藏姓名日志**：点开简历后读取候选人姓名，若姓名已在日志中则跳过收藏，避免重复收藏；新收藏的姓名自动追加进日志，日志为纯文本，可手工编辑。
- **黑名单关键词**：列表页中该条简历所在行出现任一黑名单词，直接跳过、不点开、不收藏。
- **自动刷新**：识别到底部"刷新"按钮时自动点击并等待列表更新。
- **图形界面**：界面内启动/停止、实时修改关键词、设置全局快捷键、查看运行日志与统计。
- **全局热键**：焦点在 BOSS 窗口时也能用快捷键启停（默认 `F8` 启动/停止，`F9` 紧急停止）。

| 文件 | 说明 |

## 快速开始（源码运行）

```bash
# 1. 创建并激活虚拟环境（推荐 Python 3.13）
python -m venv venv
venv\Scripts\activate.bat        # Windows

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动图形界面
python boss_gui.py
```

首次运行会自动下载 OCR 模型（约 10~30 秒），请耐心等待。

## 使用说明

1. 打开 BOSS 直聘客户端，进入简历列表页，**窗口最大化并保持在前台**。
2. 启动脚本（界面按钮或按 `F8`）。
3. 脚本会自动：
   - 扫描屏幕右侧（简历内容区）的文字；
   - 找出「公司关键词 + 同行右侧职位关键词」命中的简历；
   - 点开 → 读姓名查重 → 收藏 → 关闭 → 继续下一位；
   - 没有新目标时向下滚动；到底部出现"刷新"按钮时点击刷新。
4. 需要停止时，再按一次 `F8`，或按 `F9` 紧急停止。

### 界面可配置项

- **公司关键词**：任一命中即算（顿号 / 逗号 / 空格分隔）。
- **职位关键词**：出现在公司关键词右侧同一行即收藏。
- **黑名单关键词**：列表页该条简历所在行出现任一即跳过；留空表示不启用。
- **姓名识别区域**：占屏幕比例 `左,上,右,下`，默认已适配全屏 BOSS，一般无需修改。
- **全局快捷键**：支持 `f8`、`ctrl+s`、`alt+f1` 等写法。

所有设置保存在同目录的 `gui_config.json`，下次启动自动载入。

## 已收藏姓名日志

日志文件位于用户主目录：

```
C:\Users\<用户名>\BOSS_ResumeCollector\collected_names.log
```

- 纯文本，一行一个姓名，UTF-8 编码，可直接手工编辑。
- 每次收藏前实时读取比对，删掉某个名字后该候选人会被重新收藏。
- 界面上提供「打开日志 / 清空日志 / 刷新统计」按钮。

## 打包为 exe

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --clean boss_gui.spec
```

产物为 `dist/BOSS_ResumeCollector_GUI.exe`（单文件，内置 OCR 模型，约 430 MB，无需目标机器安装 Python）。

## 依赖

- [cnocr](https://github.com/breezedeus/cnocr) / cnstd —— 轻量中文 OCR（不依赖 PaddlePaddle）
- pyautogui —— 屏幕截图与鼠标键盘模拟
- PySide6 —— 图形界面
- opencv-python、numpy、Pillow —— 图像处理
- keyboard —— 全局热键

---

## 注意事项

- 运行期间请勿遮挡、移动或缩放 BOSS 客户端窗口，否则坐标会错位。
- 屏幕分辨率或界面布局变化后，如姓名识别不准，可在界面中微调「姓名识别区域」。
- 本工具仅用于提高个人简历筛选效率，请遵守目标平台的使用条款，合理控制使用频率。
